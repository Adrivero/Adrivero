# github/Adrivero
I'm Adrián, an Aerospace Engineer currently studying a MSc in Applied and Computational Mathematics whilst pursuing a quantitative research and algorithmic trading career. In my free time, I enjoy learning new things and working on my personal projects. Through these projects, I aim not only to apply the concepts I learn but also to invest my own capital based on the strategies I develop. I hope you find them useful and do not hesitate to message me with new ideas,improvements or bugs you may find!

## Brief summary of my repositories:
- [Fully integrated trading tool (Fitt)](https://github.com/Adrivero/Fitt) -> A project that aims to be the only Python library I need for the entire lifecycle of a trading strategy and model implementation, from development and backtesting to deployment and portfolio allocation.
- [Multilayer Perceptron and Strategy](https://github.com/Adrivero/MultilayerPerceptronStrategy) -> I coded from scratch a simple Multilayer perceptron and then used it to predict the closing prices of stocks. Includes a simple backtest.
- [Multiagentic Reinforcement Learning for Skyjo](https://github.com/Adrivero/skyjo_agent) -> (In development) This project aims to learn a policy via competitive **multi-agentic reinforcement learning (MARL)** to play the card game SKYJO™. 
- [FDM Simulation](https://github.com/Adrivero/FiniteDifferenceMethodSphere) -> Finite Difference Method (FDM) coded from scratch and used to solve the transient heat equation PDE on a sphere.
